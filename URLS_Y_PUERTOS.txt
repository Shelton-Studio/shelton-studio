ENDPOINTS API
═════════════════════════════════════════════════════════════════════════

GENERAR CONTENIDO
  POST /api/generate
  Body: {"prompt": "...", "comfyui_location": "local"}

VERIFICAR ESTADO
  GET /api/status/{job_id}

VER CONTENIDO
  GET /api/content/{content_id}

APROBAR/RECHAZAR
  POST /api/approve
  Body: {"content_id": "...", "approved": true/false}

VER HISTORIAL
  GET /api/history?skip=0&limit=20

VERIFICAR SALUD
  GET /api/health

CÓMO CONECTARSE DESDE OTROS DISPOSITIVOS
═════════════════════════════════════════════════════════════════════════

Si quieres acceder desde otra máquina en la red:

1. Obtén tu IP local:
   Windows:  ipconfig (busca IPv4 Address)
   Linux:    hostname -I
   Mac:      ifconfig

2. Usa esa IP en lugar de localhost:
   http://<tu-ip>:8000

3. Para API:
   http://<tu-ip>:8000/api/generate

EJEMPLO:
  Si tu IP es 192.168.1.100:
  http://192.168.1.100:8000

PUERTOS USADOS
═════════════════════════════════════════════════════════════════════════

PROBLEMAS DE CONEXIÓN
═════════════════════════════════════════════════════════════════════════

Shelton no abre:
  - ¿Puerto 8000 está libre?
  - ¿Ejecutaste python app/main.py?
  - Espera 10 segundos después de iniciar

ComfyUI no responde:
  - ¿http://localhost:8188 está accesible?
  - ¿Está corriendo ComfyUI en otra ventana?
  - Reinicia ComfyUI

API key no funciona:
  - ¿Está en .env?
  - ¿Es válida tu clave?
  - ¿Apunta a la URL correcta?

═════════════════════════════════════════════════════════════════════════

RESET/LIMPIEZA
═════════════════════════════════════════════════════════════════════════

Eliminar base de datos:
  Borra: shelton.db
  Luego ejecuta: python init_db.py

Eliminar imágenes generadas:
  Borra la carpeta: generated_images/

Reiniciar todo:
  Borra .db y generated_images/
  Luego inicia normalmente
