    → Genera contenido

  python cli/shelton_cli.py status <job-id>
    → Revisa estado de un trabajo

  python cli/shelton_cli.py history
    → Ve historial de contenido

    → Aprueba contenido

  python cli/shelton_cli.py health
    → Verifica que la API esté funcionando

🔧 FLUJO DE TRABAJO

  1. Tú escribes un prompt simple
        ↓
  2. Shelton lo distribuye entre 5 agentes en orden:
     • Copywriter → Enriquece el prompt
     • Strategist → Define estrategia
     • Generator → Genera imagen con Z-Image Turbo
     • Editor → Refina con Qwen-Image-Edit
     • QA Judge → Valida calidad
        ↓
  3. El resultado se muestra en el dashboard
        ↓
  4. Tú apruebas o rechazas
        ↓
  5. Se guarda en la base de datos

❓ PROBLEMAS?

  1. ComfyUI no responde
     → Asegúrate que está corriendo en http://localhost:8188

  2. API key no funciona
     → Verifica que .env tenga tu clave correcta
     → Obtén una nueva en: https://console.anthropic.com

  3. Timeout en generación
     → ComfyUI está cargando modelos, espera más
     → Aumenta timeout en comfyui/client.py

  4. Modelos no encontrados
     → Sigue SETUP_COMFYUI.md para descargar e instalar
